# replacearr.com

Marketing site for [Replacearr](https://github.com/replacearr/replacearr) — React 19, Vite, React Router, Motion, plain CSS.

## Pages

- `/` — brand hero
- `/product` — capabilities
- `/install` — Docker / GitHub get-started
- `/gallery` — UI screenshots

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run build
```

`dist/` is deployed to GitHub Pages (custom domain via `public/CNAME`). See [AGENTS.md](./AGENTS.md).
